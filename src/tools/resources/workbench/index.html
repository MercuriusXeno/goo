_constants each constant reads only the constants above it; the game's parser checks each as you type
Deleting it removes every entry below whole, and each removed constant's readers with it.

The game's lexer reads integers, $name, $tree.type, + - * /, parentheses and a leading count ("9 $iron_nugget"). A tree constant is an object of per-type expressions, such as {"leaf": "$base"}.

The parser applies each block top to bottom: a formula ("metal / 4 -> yore / 9", "type / N -> 0"), an additive ("+$waxed"), a stack ("2 @oxidation_metal"), then an assignment keyed by its target group ("#exposed": "#copper @exposed_metal @exposed_pulse", a parallel copy "#source * 3 / 4").
